# Housing Price Prediction API

This project is a simple regression model that predicts housing prices based on various features such as square footage, number of bedrooms, etc.

## Endpoints
- `/predict` - Accepts housing features and returns price predictions.
- `/model-info` - Returns model coefficients and performance metrics.
- `/health` - Health check endpoint to verify if the service is running.

## Technologies Used
- Python 3.12+
- FastAPI
- Scikit-learn
- Docker
